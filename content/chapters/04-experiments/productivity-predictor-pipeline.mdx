Predicts garment-worker productivity from operational features — department, team size, targeted productivity, SMV, work in progress, overtime, incentives, idle time, and worker counts. A single entry point handles data preparation, model training and evaluation; FastAPI exposes `/health` and `/predict` endpoints backed by a persisted `productivity_model.joblib` artifact, and a Streamlit dashboard calls the prediction API with a configurable backend URL. Optional MLflow experiment tracking and Docker deployment are documented alongside the test suite.

No evaluation metrics are published for this project yet.
